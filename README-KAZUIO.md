# Kazuio — Home refinada

Esta versão parte do projeto gerado pela V0 e aplica uma rodada de direção de arte:

- logo oficial do Kazuio (mark real extraído do material de identidade fornecido);
- hero sem moldura/card, com integração por máscaras e gradientes;
- iconografia própria em SVG para os diferenciais e pilares;
- Psicologia · Fé · Filosofia tratados como uma família visual;
- menos sensação de SaaS/cards e mais composição editorial;
- celular com conversa em código, incluindo voz e envio;
- biblioteca com tratamento editorial;
- FAQ real para o item do menu;
- CTAs apontando para https://app.kazuio.com/;
- footer atualizado para 2026;
- responsividade e acessibilidade básicas preservadas.

## Como usar

Substitua os arquivos do projeto atual pelos arquivos deste pacote e rode normalmente com o gerenciador de pacotes já usado no projeto.

O pacote mantém o `package.json` e o `pnpm-lock.yaml` originais da V0.

## Assets importantes

`public/brand/kazuio-mark.png` — símbolo oficial usado no header e no mockup do celular.

`public/brand/kazuio-logo-official.png` — lockup oficial de referência.
